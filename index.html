A finished job is not proof.

  1. GPU requirement, workload, duration, budget and release rule are fixed at creation.

  2. Escrow locks the agreed amount, so a provider can see payment exists.

  3. Heartbeats and an output hash decide whether the job met its rule.

  4. Each claim carries its source, so onchain state never blurs into a report.

The safest claim is the one BRUT does not make.

  • No GPU ownership

    BRUT runs no hardware. Compute stays on provider machines.

  • No fund custody

    Escrow follows the job rules, not a company account.

  • No proven hardware

    A GPU claim stays reported until attestation backs it.

  • No dispute court

    The first build has no arbitration. Timeouts decide failure.

First build scope

The first build stays deliberately narrow so the settlement loop can be trusted.
